# 灵瑞伴看 — 抖音伴看 AI Agent

> 刷到不同视频，召唤不同灵瑞，把"看见"变成"能用"。

## 项目介绍

《灵瑞伴看》是一个陪你刷视频的视觉 Agent。它会根据视频内容自动召唤不同灵瑞：

| 灵瑞 | 能力 | 场景 |
|------|------|------|
| 🦁 辟邪 | 种草避坑，反冲动消费 | 种草视频 |
| 🐉 白泽 | 教程拆解，行动卡生成 | 知识/教程视频 |
| 🦊 九尾 | 风格结构识别，个人化迁移 | 穿搭/风格视频 |
| 🦌 天禄 | 探店/旅行变现实计划 | 探店/旅行视频 |
| 🐢 玄龟 | 自律焦虑降噪，低负担计划 | 自律/焦虑视频 |

## 本地启动

```bash

npm install

npm run dev

# 构建
npm run build

# 生产模式
npm start
```

访问 http://localhost:3000 即可体验。

## 环境变量

复制 `.env.example` 为 `.env.local`：

```bash
cp .env.example .env.local
```

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `AI_MODE` | `mock` 使用预置结果，`real` 尝试调用真实 API | `mock` |
| `LLM_BASE_URL` | OpenAI 兼容 API 地址 | - |
| `LLM_API_KEY` | API Key（仅服务端使用） | - |
| `LLM_MODEL` | 模型名称 | - |
| `LLM_TIMEOUT_MS` | 真实 API 超时时间，超时后自动兜底 | `18000` |

## 如何切换 mock / real

- **mock 模式**（默认）：`AI_MODE=mock`，直接返回预置的高质量 mock 结果，无需 API key。
- **real 模式**：`AI_MODE=real`，配置 `LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL` 后，会尝试调用真实多模态 API。如果 API 失败、超时或返回异常，自动 fallback 到 mock 模式。

支持的 API 格式：OpenAI 兼容（OpenAI、DeepSeek、Moonshot、SiliconFlow 等）。

## AI 角色系统

五只灵瑞不是换皮客服机器人，而是五种伴看能力：

- **辟邪**：种草避坑，拆营销情绪、证据缺口和买前 3 问。
- **白泽**：教程拆解，把收藏夹内容变成 3–5 步行动卡。
- **九尾**：风格迁移，拆颜色、比例、材质、机位等结构，不评价颜值。
- **天禄**：生活计划，把探店/旅行灵感变成时间、预算、路线和避坑。
- **玄龟**：低负担节奏，把自律焦虑降噪成低电量/标准/爆发三档计划。

`/api/analyze` 会统一走服务端 `analyzeWithFallback`：`AI_MODE=real` 且 `LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL` 完整时尝试真实模型；缺 key、超时、HTTP 错误、JSON 解析失败或 schema 校验失败时，都会返回对应灵瑞的 mock 结果，并带 `debug.fallbackReason`。

安全边界：不接真实抖音 API、商品库、地图、支付或登录；`LLM_API_KEY` 只通过服务端环境变量读取，不进入前端组件或浏览器 bundle。

## 5 个灵瑞场景

1. **辟邪 · 种草避坑**：识别种草视频中的卖点、夸张话术，给出能买/慎买/先别买建议。
2. **白泽 · 教程拆解**：把教程视频拆成关键步骤、准备材料、易错点和第一步行动。
3. **九尾 · 风格识别**：分析视频中的风格结构，结合用户上传的照片给出个人化迁移建议。
4. **天禄 · 计划安排**：把探店/旅行视频变成现实可执行计划，包括时间、预算、路线。
5. **玄龟 · 低负担计划**：把鸡血/焦虑视频降噪，改成适合用户当前状态的低负担版本。

## 已实现功能

- ✅ 模拟抖音竖屏信息流（9:16 比例）
- ✅ 5 条视频场景切换（支持滚轮、键盘、触摸滑动、按钮）
- ✅ 每条视频对应灵瑞气泡和 hookLine
- ✅ 分析面板：问题输入、画面圈选、图片上传（九尾）
- ✅ 分析过程动效（4 步进度）
- ✅ 统一结果卡展示
- ✅ 分享卡（可截图分享）
- ✅ 复制卡片文案
- ✅ Mock / Real 双模式 + 自动 fallback
- ✅ API status badge（真实分析 / 模拟兜底）
- ✅ localStorage 记录游玩状态
- ✅ 手机窄屏适配
